# 토큰 절약 제작 모드 (에이전트용)

브리프가 주어진 상태에서 영상 1편을 만들 때 아래를 지킨다.

1. 이미지 검색을 하지 않는다. 브리프가 지정한 로컬 후보 폴더의 파일만 쓴다.
2. 기사 재확인을 하지 않는다. 사실 검증은 기획 단계(브리프)에서 끝났다.
3. 장면당 이미지는 1장, 출처 기록은 파일명 수준으로만 남긴다.
4. 렌더는 한 번에 끝낸다. 렌더 전에 반드시 자가 점검을 한다.
   - 자막은 2줄, 각 줄 12자 이내
   - 인물 얼굴이 자막 박스 위(화면 y<1120)에 있고 잘리지 않는다
   - 방송사 로고·프로그램 배지·원본 자막·매체 워터마크가 프레임에 남지 않는다
   - 같은 원본 사진을 두 장면에 쓰지 않는다(크롭·확대·반전도 중복)
5. 콘택트시트는 만들되 에이전트가 직접 분석하지 않는다. 검수는 기획자(메인)가 한다.
6. 업로드는 하지 않는다. `output/<ROOT>-upload.mp4`까지만 만든다.
   재인코딩: `bash scripts/py.sh scripts/tool.py ffmpeg -i <입력> -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart <출력>`
7. TTS는 Supertonic F1, 기본 속도 1.18. 길이가 30초 미만이면 속도를 낮춰 30~48초에 맞춘다.
8. 최종 보고는 10줄 이내. 파일 경로, 길이, 검수 결과, 사용 토큰 수를 남긴다.
