# 쇼츠 혼자 시작하기 가이드

> **이 파일을 받은 AI에게**
> 이 문서는 카드뉴스형 AI 쇼츠 강의(2026.10.7)를 들은 40~60대 수강생이 집에서 혼자 따라 하기 위한 안내서입니다.
> 사용자에게 **한 번에 한 단계씩만** 안내해 주세요. 각 단계를 쉬운 말로 짧게 설명하고, 사용자가 "했어요"라고 하면 다음 단계로 넘어가세요.
> 먼저 사용자에게 두 가지를 물어보세요. ① 컴퓨터가 Mac인지 Windows인지 ② 쓰는 AI 앱이 ChatGPT(Codex), Claude(Code 탭), Gemini(Antigravity) 중 무엇이고 유료인지.
> 사용자가 터미널·PowerShell에서 할 일은 아래에 적힌 명령을 그대로 붙여 넣는 것뿐입니다. 다른 명령을 만들어 시키지 마세요.
> 막히면 화면 사진을 보여 달라고 하고, 아래 "막힐 때" 항목을 먼저 확인하세요.

---

## 0. 준비물

- 쇼츠를 만들 노트북 (Mac: macOS 13 이상 / Windows 10·11, 64비트), 빈 공간 8GB 이상
- AI 유료 구독 하나: **ChatGPT Plus**, **Claude Pro**, 또는 **Gemini 유료 요금제(Google AI Pro 등)**
  - 무료 요금제는 사용량이 적어서 영상 1편을 끝까지 만들기 전에 멈출 수 있어요.
- 구독한 AI의 **데스크톱 앱** (인터넷 창이 아니라 앱)
  - ChatGPT: https://chatgpt.com/download → 앱 안에서 **Codex** 사용
  - Claude: https://claude.com/download → 앱 왼쪽 위 **Code** 탭 사용
  - Gemini: https://antigravity.google/download → **Antigravity** 앱 사용 (Gemini 앱으로는 안 돼요)

## 1. 설치하기 (처음 한 번, 약 30분 · 3GB)

설치 안내 페이지: https://deanlee1113.github.io/issuekiller-setup/

와이파이가 좋은 곳에서 하세요. 이미 설치했다면 **한 번 더 실행해도 괜찮아요.** 된 부분은 건너뛰고 새 기능만 받아요.

**Mac**
1. `⌘ command` + `스페이스` → `터미널` 입력 → `Enter`
2. 아래 한 줄을 복사해 터미널에 붙여 넣고 `Enter`

```
curl -fsSL https://raw.githubusercontent.com/deanlee1113/issuekiller-setup/main/get.sh | bash
```

**Windows**
1. `윈도우 키` → `PowerShell` 입력 → `Enter`
2. 아래 한 줄을 복사해 파란 창에 **마우스 오른쪽 클릭**으로 붙여 넣고 `Enter`

```
irm https://raw.githubusercontent.com/deanlee1113/issuekiller-setup/main/get.ps1 | iex
```

3. 10~30분 기다리면 마지막에 **"설치가 모두 끝났습니다."**가 나와요.

## 2. AI 앱에서 폴더 열기

- ChatGPT 앱 → 위쪽 **Codex** → 폴더 열기 → 홈 폴더의 **issuekiller** → "이 폴더를 신뢰할까요?"에 **신뢰**
- Claude 앱 → 왼쪽 위 **Code** → 폴더 선택 → 홈 폴더의 **issuekiller**
- Antigravity 앱 → Google 로그인 → **프로젝트 추가** → 홈 폴더의 **issuekiller**

(홈 폴더 = Mac은 `/Users/내이름`, Windows는 `C:\Users\내이름`)

## 3. 미션 (아래 문장을 AI 앱에 그대로 복사해 넣으세요. [ ] 부분만 내 것으로 바꾸기)

**미션 1 · 내 채널 정하기**
```
유튜브 쇼츠 채널을 새로 시작하려고 해.
나를 한 줄로 소개하면: [예: 부산에서 반려견 카페를 하는 50대]
이런 나에게 맞는 채널 아이디어 3개를 추천해 줘.
각각 '채널 이름 / 누구에게 / 무엇을 / 첫 영상 주제 예시 2개' 형식으로, 쉬운 말로 짧게.
```
고른 뒤:
```
내 채널 이름은 '[채널 이름]'이고, 주제는 '[누구에게 + 무엇을]'이야.
채널 설정(channel.json)의 채널 이름을 이걸로 바꿔 저장하고,
채널 주제는 이 폴더에 내 규칙 파일(my-rules.md)을 만들어 적어 둬. (이미 있으면 거기에 추가)
저장했는지 짧게 알려 줘.
```

**미션 2 · 첫 영상 만들기 (7~12분 기다리기)**
```
'[이번 영상 주제]' 주제로 쇼츠 1편 만들어 줘.
사진은 인터넷에서 주제와 관련된 실제 사진을 찾아서 써 줘. 저작권 걱정 없는 무료 사진 사이트(Pexels, Unsplash, Pixabay)에서만 가져오고, 장면마다 다른 사진으로, 출처는 기록해 둬. 맞는 사진을 못 찾은 장면만 연습용 그림으로 채워 줘.
만드는 동안 지금 무엇을 하는지 쉬운 말로 짧게 알려 주고,
다 만들면 영상 파일 위치와 한 장면 사진을 보여 줘. 유튜브에는 올리지 마.
```

**미션 3 · 검수하기** (영상은 issuekiller → output 폴더)
```
방금 만든 영상을 검수해 줘.
첫 1초에 내용이 전달되는지, 사진이 주제와 맞는지, 자막 길이, 목소리 끊김, 영상 길이, 마지막 인사말을 확인하고
고칠 점 3가지를 중요한 순서대로 쉬운 말로 알려 줘.
```

**미션 4 · 고쳐서 다시 만들고 규칙으로 남기기**
```
방금 알려 준 고칠 점 중 1번과 2번을 반영해서 영상을 다시 만들어 줘.
그리고 앞으로 만드는 영상은 이렇게 해 줘.
- 대본 말투: [친근한 존댓말]
- 쓰지 말 것: ['충격', '경악' 같은 자극적인 단어]
- 방금 고친 1번, 2번
이것들을 내 규칙 파일(my-rules.md)에 저장하고, 저장된 내용을 보여 줘.
앞으로 영상을 만들 때는 이 파일을 먼저 읽고 따라 줘.
```

**미션 5 · 화면 틀 꾸미기** (바꾸고 싶은 줄만 남기기)
```
화면 틀을 이렇게 바꿔 줘.
- 채널 배지를 [초록색] 바탕에 흰 글씨로
- 오른쪽 위 문구를 '[매주 금요일 새 영상]'(으)로
- 제목 글씨를 지금보다 조금 더 크게
- 자막 상자를 흰 바탕에 검은 글씨로
원래 화면 틀(src/NewsTemplate.tsx)은 고치지 말고, 복사본(src/MyTemplate.tsx)을 만들어서 거기서 바꿔 줘.
앞으로 내 영상은 이 복사본을 쓰도록 내 규칙 파일(my-rules.md)에도 적어 두고,
바꾼 화면 틀로 방금 영상을 다시 만들어 한 장면만 보여 줘.
```

**미션 6 · 작업 설명서(스킬)를 내 채널에 맞게**
```
받은 쇼츠 스킬(issuekiller-shorts)을 내 채널에 맞게 바꾸고 싶어.
원본은 고치지 말고, 통째로 복사해서 새 스킬 'my-shorts'를 만들어 줘. (.agents/skills/my-shorts 와 .claude/skills/my-shorts 두 곳)
복사본에서 연예 뉴스 대신 '[채널 주제]'을(를) 다루도록 고치고, 내 규칙 파일(my-rules.md)을 먼저 읽도록 적어 줘.
무엇을 바꿨는지, 원래 스킬과 뭐가 다른지 세 줄로 쉽게 알려 줘.
```

**미션 7 · 한 편 더, 그리고 올릴 준비**
```
내 규칙 파일(my-rules.md)을 먼저 읽고, 내 스킬(my-shorts)로 '[채널 이름]' 채널에 올릴 쇼츠 1편을 만들어 줘.
주제는 '[채널 주제]'에 맞게 네가 하나 골라 줘. 사진은 무료 사진 사이트(Pexels, Unsplash, Pixabay)에서만 가져오고 출처를 기록해 줘.
다 만들면 한 장면 사진을 보여 주고, 이 영상을 유튜브 쇼츠에 올릴 수 있게
제목 후보 3개(30자 이내), 설명 3줄, 태그 10개도 만들어 줘.
설명 끝에는 사진 출처와 'AI로 만든 목소리를 포함하고 있습니다.'를 넣어 줘.
```

**강의 시간에 무료 채팅으로 미리 만든 대본·규칙이 있다면**
```
아래는 내가 미리 정리한 [대본 / 내 채널 규칙]이야. 이걸 그대로 반영해서 쇼츠 1편 만들어 줘.
(여기에 붙여 넣기)
```

## 4. 유튜브에 올리기 (휴대폰)

1. 영상 파일을 카카오톡 "나와의 채팅"으로 보내 휴대폰에 저장
2. 유튜브 앱 → 아래 `+` → **Shorts** → 저장한 영상 선택
3. 미션 7에서 받은 제목·설명·태그를 붙여 넣기, 처음엔 **비공개**
4. "AI로 만든 콘텐츠"를 물으면 사실대로 체크

## 5. 막힐 때

- **"허용할까요?"가 나와요** → 내용을 읽고 허용. 영상 만드는 명령은 대부분 미리 허용돼 있어요.
- **설치가 중간에 멈춘 것 같아요** → 진행 막대가 움직이면 기다리기. 15분 넘게 그대로면 `Ctrl + C`로 멈추고 설치 명령을 한 번 더.
- **Windows에서 'AhnLab 위협 행위 차단' 창** → 은행용 보안 프로그램이 설치 방식을 막은 것. 작업 표시줄 `^` → AhnLab 아이콘 오른쪽 클릭 → 종료 → 설치 명령 다시 → 끝나면 컴퓨터 다시 켜기.
- **영상이 30초보다 짧아요** → "장면마다 한 문장씩 더 넣어서 35초 이상으로 다시 만들어 줘"
- **AI가 이상하게 고쳤어요** → "방금 바꾼 걸 되돌려 줘" / "원래 화면 틀(NewsTemplate)로 되돌려 줘. 내가 만든 복사본은 지우지 말고 둬"
- 그래도 안 되면 화면 사진을 찍어 강의 단톡방에 올려 주세요.
