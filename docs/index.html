강의 전에
이것만 설치하세요

실습 시간에는 여러분의 컴퓨터로 직접 쇼츠를 만듭니다. 설치 파일이 약 3GB라 강의장 와이파이로는 시간이 모자라니, 강의 전날까지 집이나 사무실에서 마쳐 주세요. 터미널에 명령어 한 줄만 붙여넣으면 나머지는 자동입니다.

관리자 비밀번호 없음 Xcode · Homebrew 없음 폴더 하나에만 설치, 지우면 원상복구 10~30분
지금 휴대폰으로 보고 계신 것 같아요. 설치는 실습에 가져올 컴퓨터에서 이 페이지를 열어 진행해 주세요.

Mac

macOS 13 (Ventura) 이상
Apple Silicon (M1~M4) · Intel 모두 가능
여유 공간 8GB

터미널을 열고 이 한 줄을 붙여넣은 뒤 Enter

curl -fsSL https://raw.githubusercontent.com/deanlee1113/issuekiller-setup/main/get.sh | bash

Windows

Windows 10 (1809 이상) · Windows 11
64비트 (ARM 노트북은 지원 안 함)
여유 공간 8GB

PowerShell을 열고 이 한 줄을 붙여넣은 뒤 Enter

irm https://raw.githubusercontent.com/deanlee1113/issuekiller-setup/main/get.ps1 | iex

이 한 줄은 작은 설치 도우미를 내려받아 실행합니다. 도우미가 필요한 프로그램(약 3GB)을 인터넷에서 직접 받아 issuekiller-tools 폴더에 설치합니다. 회사 노트북은 보안 프로그램이 다운로드를 막을 수 있으니 개인 컴퓨터를 권장합니다.

명령어 방식이 안 되면 → 설치 파일을 zip으로 받기

Mac

압축을 풀어 issuekiller 폴더를 홈 폴더로 옮긴 뒤, 터미널에 bash 를 입력하고 setup/mac/install.command 파일을 창 안으로 끌어다 놓고 Enter.

Windows

압축을 풀어 issuekiller 폴더를 C:\Users\내이름 아래로 옮긴 뒤, setup\windows\install.bat 더블클릭. 파란 “PC 보호” 창이 뜨면 추가 정보 → 실행.

설치 순서

  1. 터미널을 엽니다
    ⌘ + Space를 누르고 터미널이라고 입력한 뒤 Enter. 흰색 또는 검은색 글자 창이 열립니다.
  2. 위의 Mac 명령어를 복사해 터미널에 붙여넣고 Enter
    노란 복사 버튼을 누른 뒤 터미널 창을 클릭하고 ⌘ + V, 그리고 Enter. 비밀번호는 묻지 않습니다. 중간에 “Xcode 명령어 라인 도구” 창이 뜨면 지금 안 함을 누르세요.
  3. 10~30분 기다립니다
    마지막에 “설치가 모두 끝났습니다.”와 확인표의 ✅가 보이면 완료. ❌가 있으면 그 화면을 캡처해 강사에게 보내주세요.
  4. 터미널을 완전히 닫고 새로 연 뒤 claude 입력
    브라우저가 열리면 Claude 계정으로 로그인합니다. 로그인이 끝나면 터미널에 /exit를 입력해 나옵니다.
중간에 끊겼거나 상태를 다시 확인하고 싶으면 같은 명령어를 다시 붙여넣으면 됩니다. 끝난 항목은 건너뜁니다. 확인만 하려면 bash ~/issuekiller/setup/mac/check.command
  1. PowerShell을 엽니다
    Windows 키를 누르고 PowerShell이라고 입력한 뒤 Enter. 파란 글자 창이 열립니다. “관리자 권한으로 실행”은 필요 없습니다.
  2. 위의 Windows 명령어를 복사해 붙여넣고 Enter
    노란 복사 버튼을 누른 뒤 파란 창 안에서 오른쪽 클릭(또는 Ctrl + V)하면 붙여넣어집니다. 그리고 Enter.
  3. 10~30분 기다립니다
    중간에 창을 닫지 마세요. 마지막에 “설치가 모두 끝났습니다.”와 확인표의 [OK]가 보이면 완료. [XX]가 있으면 그 화면을 캡처해 강사에게 보내주세요.
  4. 창을 닫고 PowerShell을 새로 연 뒤 claude 입력
    브라우저가 열리면 Claude 계정으로 로그인합니다. 로그인이 끝나면 /exit를 입력해 나옵니다.
중간에 끊겼거나 상태를 다시 확인하고 싶으면 같은 명령어를 다시 붙여넣으면 됩니다. 끝난 항목은 건너뜁니다. 확인만 하려면 탐색기에서 C:\Users\내이름\issuekiller\setup\windows\check.bat 더블클릭.
Claude 계정은 미리 준비해 주세요. 실습에서 영상을 만들어 주는 Claude Code는 유료 구독 계정(Pro 이상)으로 로그인해야 동작합니다.

설치되는 것

영상을 만드는 데 필요한 것만 담았습니다. 모두 issuekiller-tools 폴더와 issuekiller 프로젝트 폴더 안에만 들어가고, 이미 설치된 다른 프로그램은 건드리지 않습니다.

프로그램하는 일용량
Node.js영상 렌더링 엔진(Remotion)을 돌립니다50MB
ffmpeg영상·음성 파일을 자르고 붙이고 검사합니다160MB
Python 3.12 + 음성 패키지한국어 나레이션 합성(Supertonic)과 음성 검증(Whisper)300MB
음성 모델 2종위 패키지가 쓰는 학습 모델850MB
Claude Code대본·장면·자막을 만들어 주는 AI 도우미100MB
Git BashWindows만Claude Code가 명령을 실행할 때 씁니다300MB
영상 프로젝트 패키지 + 렌더용 브라우저실습 프로젝트가 쓰는 부품과 화면을 그리는 브라우저1.5GB

합계 약 3GB. 설치가 끝나면 2초짜리 확인용 영상 test-render.mp4가 실제로 만들어져야 성공입니다.

자주 묻는 질문

중간에 실패했다고 나와요
같은 명령어를 다시 붙여넣어 실행하세요. 끝난 항목은 건너뛰고 실패한 곳부터 이어서 합니다. 두 번째도 실패하면 창을 캡처해 강사에게 보내주세요. 로그 파일은 issuekiller-tools/install-mac.log(Mac) 또는 issuekiller-tools\install-windows.log(Windows)에 있습니다.
“Xcode 명령어 라인 도구를 설치하시겠습니까?” 창이 떠요 (Mac)
필요 없습니다. 나중에 또는 지금 안 함을 누르세요. 설치 도우미는 Xcode 없이 동작합니다.
이미 Node.js나 Python이 깔려 있어요
상관없습니다. 기존 것에 손대지 않고 issuekiller-tools 폴더 안에 따로 설치합니다.
회사 노트북인데 될까요?
관리자 권한은 필요 없지만, 회사 보안 프로그램이 nodejs.org · github.com · huggingface.co · pypi.org 같은 곳의 다운로드를 막으면 실패합니다. 되도록 개인 컴퓨터를 준비해 주세요.
인텔 맥인데요
됩니다. macOS 13 이상이면 자동으로 인텔용 파일을 받습니다. 2017년 이전 모델은 macOS 13이 안 올라가니 확인해 주세요. (Apple 메뉴 → 이 Mac에 관하여)
Windows 버전을 어떻게 확인하나요?
Windows 키 + R을 누르고 winver를 입력하면 나옵니다. Windows 10은 버전 1809 이상이어야 합니다. Windows 11은 모두 됩니다.
강의가 끝나고 다 지우고 싶어요
issuekiller-tools 폴더, issuekiller 프로젝트 폴더, 그리고 .cache/supertonic3·.cache/huggingface 폴더를 지우면 됩니다. 프로젝트 폴더 안 README.md에 자세히 적어 두었습니다.
파란 “Windows의 PC 보호” 창이 떠요
서명되지 않은 설치 파일이라 나오는 안내입니다. 추가 정보 → 실행을 누르면 계속됩니다. 명령어 한 줄 방식에서는 보통 뜨지 않습니다.
명령어를 붙여넣었는데 아무 일도 안 일어나요
Enter를 눌러야 시작됩니다. Windows에서 붙여넣기가 안 되면 창 안에서 오른쪽 클릭을 해 보세요. 그래도 안 되면 위의 zip으로 받기를 이용하세요.
