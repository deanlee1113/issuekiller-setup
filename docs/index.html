아래 5단계를 순서대로 따라 하세요.
영상 도구와 실습 파일이 한 번에 설치됩니다.

  • ①실습에 가져올 노트북
  • ②집 와이파이 (약 3GB)
  • ③Claude 유료 계정 (Pro 이상)
📱 지금 휴대폰으로 보고 계세요. 설치는 노트북에서 해야 해요. 노트북에서 이 주소를 여세요:

내 노트북은 어떤 컴퓨터인가요?

설치 순서

  1. 1

    ‘터미널’을 엽니다

    ⌘ command + 스페이스 → 터미널 입력 → Enter

    글자를 쓰는 작은 창이 열려요.

  2. 2

    노란 버튼을 눌러 명령어를 복사합니다

    curl -fsSL https://raw.githubusercontent.com/deanlee1113/issuekiller-setup/main/get.sh | bash
  3. 3

    터미널에 붙여넣고 Enter

    터미널 창 클릭 → ⌘ command + V → Enter

    비밀번호는 묻지 않아요.

  4. 4

    창을 그대로 두고 기다립니다 (10~30분)

    이 글자가 보이면 성공이에요.

    ✅ 시험 렌더 영상
    설치가 모두 끝났습니다.

    ❌가 보이면 화면을 사진 찍어 강사에게 보내 주세요.

    ‘Xcode 설치’ 창이 뜨면 지금 안 함을 누르세요.

  5. 5

    Claude에 로그인합니다

    터미널을 닫고 다시 열기 → claude 입력 → Enter

    인터넷 창이 열리면 Claude 계정으로 로그인하세요. 끝나면 터미널에 /exit 입력.

  1. 1

    ‘PowerShell’을 엽니다

    ⊞ 윈도우 키 → PowerShell 입력 → Enter

    파란색(또는 검은색) 창이 열려요. 관리자 권한은 필요 없어요.

  2. 2

    노란 버튼을 눌러 명령어를 복사합니다

    irm https://raw.githubusercontent.com/deanlee1113/issuekiller-setup/main/get.ps1 | iex
  3. 3

    창 안에서 마우스 오른쪽 클릭, 그리고 Enter

    창 안에서 오른쪽 클릭 → Enter

    오른쪽 클릭이 붙여넣기예요. 안 되면 Ctrl + V.

  4. 4

    창을 그대로 두고 기다립니다 (10~30분)

    이 글자가 보이면 성공이에요.

    [OK] 시험 렌더 영상
    설치가 모두 끝났습니다.

    [XX]가 보이면 화면을 사진 찍어 강사에게 보내 주세요.

    ‘PC 보호’ 파란 창이 뜨면 추가 정보 → 실행을 누르세요.

  5. 5

    Claude에 로그인합니다

    창을 닫고 PowerShell 다시 열기 → claude 입력 → Enter

    인터넷 창이 열리면 Claude 계정으로 로그인하세요. 끝나면 /exit 입력.

2·3단계를 한 번 더 하세요. 끝난 부분은 건너뛰고 이어서 설치해요. 두 번째도 실패하면 화면을 사진 찍어 강사에게 보내 주세요.

붙여넣었는데 아무 일도 안 일어나요

Enter를 눌러야 시작돼요. 그래도 안 되면 창을 닫고 1단계부터 다시 하세요.

회사 노트북인데 될까요?

회사 보안 프로그램이 다운로드를 막을 수 있어요. 되도록 개인 노트북을 가져오세요.

내 컴퓨터가 설치 조건에 맞나요?

Mac — macOS 13 이상 (사과 메뉴 → 이 Mac에 관하여에서 확인)

Windows — Windows 10 또는 11, 64비트 (⊞ + R → winver)

빈 공간 8GB 이상이 필요해요.

명령어 방식이 계속 안 돼요 (파일로 받기)

설치 도우미를 파일로 받아 직접 실행하는 방법이에요. 강사가 안내할 때만 쓰세요.

압축을 풀고 issuekiller 폴더를 홈 폴더로 옮긴 뒤, 터미널에 bash 를 입력하고 setup/mac/install.command 파일을 창에 끌어다 놓고 Enter.

압축을 풀고 issuekiller 폴더를 C:\Users\내이름 아래로 옮긴 뒤, setup\windows\install.bat 더블클릭.

무엇이 설치되나요? 나중에 지울 수 있나요?

영상 만드는 도구(Node.js, ffmpeg, 음성 합성, Remotion), Claude Code, 강의 실습 파일이 설치돼요. 이미 깔려 있는 다른 프로그램은 건드리지 않아요.

지우려면 홈 폴더의 issuekiller, issuekiller-tools 폴더와 .cache/supertonic3, .cache/huggingface 폴더를 지우면 돼요.
