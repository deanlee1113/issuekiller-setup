2·3단계를 한 번 더 하세요. 끝난 부분은 건너뛰고 이어서 설치해요. 두 번째도 실패하면 화면을 사진 찍어 강사에게 보내 주세요.

Windows에서 ‘AhnLab 위협 행위 차단’ 창이 떠요

은행 사이트용 보안 프로그램(AhnLab Safe Transaction)이 설치 명령의 실행 방식을 위험하다고 보고 막은 거예요. 설치 파일에 문제가 있는 건 아니에요.

  1. 창의 확인을 누르고, 파란 PowerShell 창을 닫아요.
  2. 화면 오른쪽 아래 작업 표시줄의 ^를 눌러 AhnLab Safe Transaction 아이콘을 찾아요.
  3. 아이콘을 마우스 오른쪽으로 눌러 종료(또는 보호 중지)를 눌러요.
  4. PowerShell을 새로 열고 2·3단계(명령어 복사 → 붙여넣기)를 다시 해요. 이미 된 부분은 건너뛰고 이어서 설치돼요.
  5. 설치가 끝나면 컴퓨터를 다시 켜면 보안 프로그램도 다시 켜져요.

메뉴 이름은 버전마다 조금 다를 수 있어요. 못 찾겠으면 화면을 찍어 단톡방에 올려 주세요.

붙여넣었는데 아무 일도 안 일어나요

Enter를 눌러야 시작돼요. 그래도 안 되면 창을 닫고 1단계부터 다시 하세요.

회사 노트북인데 될까요?

회사 보안 프로그램이 다운로드를 막을 수 있어요. 되도록 개인 노트북을 가져오세요.

내 컴퓨터가 설치 조건에 맞나요?

Mac — macOS 13 이상 (사과 메뉴 → 이 Mac에 관하여에서 확인)

Windows — Windows 10 또는 11, 64비트 (⊞ + R → winver)

빈 공간 8GB 이상이 필요해요.

명령어 방식이 계속 안 돼요 (파일로 받기)

설치 도우미를 파일로 받아 직접 실행하는 방법이에요. 강사가 안내할 때만 쓰세요.

압축을 풀고 issuekiller 폴더를 홈 폴더로 옮긴 뒤, 터미널에 bash 를 입력하고 setup/mac/install.command 파일을 창에 끌어다 놓고 Enter.

압축을 풀고 issuekiller 폴더를 C:\Users\내이름 아래로 옮긴 뒤, setup\windows\install.bat 더블클릭.

무엇이 설치되나요? 나중에 지울 수 있나요?

영상 만드는 도구(Node.js, ffmpeg, 음성 합성, Remotion)와 쇼츠 제작 스킬·실습 파일, 보조 도구 Claude Code가 설치돼요. AI 앱은 준비물 안내대로 따로 설치하세요. 이미 깔려 있는 다른 프로그램은 건드리지 않아요.

지우려면 홈 폴더의 issuekiller, issuekiller-tools 폴더와 .cache/supertonic3, .cache/huggingface 폴더를 지우면 돼요.
