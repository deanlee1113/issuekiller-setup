    AI 앱 준비하기

    5분처음 한 번

    목표: 내 AI 앱에서 issuekiller 폴더를 열어, AI가 영상 만드는 도구를 쓸 수 있게 해요.

    ①내가 구독한 AI를 고르세요

    위에서 하나를 누르면 그 앱의 순서가 나와요.

    ②Claude 앱에서 폴더 열기
    1. Claude 앱을 열고 로그인해요앱이 없으면 claude.com/download 에서 받아 설치
    2. 창 맨 위(왼쪽 위)에서 Chat 옆의 Code를 눌러요Chat(일반 대화)에서는 영상을 만들 수 없어요. 꼭 Code예요.
    3. 폴더 선택을 눌러 홈 폴더 → issuekiller를 고르고 열기홈 폴더 = Mac은 집 모양 아이콘(내 이름), Windows는 C:\Users\내이름
    4. 아래 입력창에 이 페이지에서 복사한 말을 붙여 넣고 Enter
    5. "허용할까요?(Allow)"가 나오면 내용을 읽고 허용을 눌러요
    ②ChatGPT 앱에서 폴더 열기
    1. ChatGPT 앱을 열고 로그인해요앱이 없으면 chatgpt.com/download 에서 받아 설치
    2. 위쪽(또는 왼쪽)에서 Codex를 골라요일반 대화창에서는 영상을 만들 수 없어요. 꼭 Codex예요.
    3. 폴더 열기를 눌러 홈 폴더 → issuekiller를 고르고 열기
    4. "이 폴더를 신뢰할까요?"가 나오면 신뢰를 눌러요신뢰해야 영상 만드는 명령을 미리 허용한 설정이 켜져요
    5. 입력창에 이 페이지에서 복사한 말을 붙여 넣고 Enter
    ②Antigravity 앱에서 폴더 열기

    Gemini 앱이 아니라 Antigravity 앱이에요. 화면이 코딩 프로그램처럼 생겼지만 순서대로만 하면 돼요.

    1. Antigravity 앱을 열고 Google 계정으로 로그인해요앱이 없으면 antigravity.google/download 에서 받아 설치
    2. 첫 화면에서 프로젝트 추가(폴더 열기) → 홈 폴더 → issuekiller 선택
    3. 에이전트 대화창(AI에게 말하는 칸)을 열어요보통 화면 오른쪽에 있어요
    4. 대화창에 이 페이지에서 복사한 말을 붙여 넣고 Enter
    5. 명령을 실행해도 되는지 물으면 내용을 읽고 허용(Accept)을 눌러요

    issuekiller 폴더가 안 보이면? 폴더 고르는 창이 뜬 상태에서
    Mac: ⌘ command + shift + H → 내 이름으로 된 홈 폴더로 이동 → issuekiller → 열기
    Windows: 창 맨 위 주소칸에 %USERPROFILE%\issuekiller 입력 → Enter → 폴더 선택

    ③폴더가 제대로 열렸는지 확인해요

    AI가 "쇼츠 제작 키트가 맞다"고 답하고 채널 설정을 보여 주면 성공이에요. "폴더를 찾을 수 없다"고 하면 ②의 폴더 열기를 다시 해 보세요.

    버튼 이름은 앱 버전에 따라 조금 다를 수 있어요. 막히면 손을 들어 주세요.

    첫 영상 만들기

    10분기다리며 읽기

    목표: 주제에 맞는 실제 사진으로 첫 쇼츠 1편을 끝까지 만들어 봐요.

    ①이번 영상 주제를 골라요

    미션 1에서 AI가 준 "첫 영상 주제 예시" 중 하나를 그대로 옮겨 적으세요. 더 보고 싶으면 아래 추천 받기를 먼저 하세요.

    ②쇼츠 1편 만들기
    기다리는 동안 (7~12분): 지금 AI가 하는 일
    1. 대본: 주제에 맞춰 장면별 자막을 써요.
    2. 사진 찾기: 무료 사진 사이트(Pexels·Unsplash·Pixabay)에서 주제에 맞는 실제 사진을 장면마다 찾아 내려받아요. 뉴스·블로그 사진은 저작권 때문에 쓰지 않아요.
    3. 목소리: 내 컴퓨터에 설치된 음성 엔진으로 읽어요.
    4. 자막 맞추기: 목소리와 자막 타이밍을 맞춰요.
    5. 영상 만들기·검수: 영상으로 만들고, 소리가 끊긴 곳이나 너무 짧은 곳이 없는지 스스로 점검해요.

    "허용할까요?"가 나오면 내용을 읽고 허용. 오래 멈춰 있으면 "지금 어디까지 했어?"라고 물어보세요.

    내 눈으로 검수하기

    5분직접 보기

    목표: AI는 실수할 수 있어요. 직접 보고 고칠 점을 찾아요.

    ①영상을 열어 처음부터 끝까지 보세요

    영상 파일은 issuekiller → output 폴더에 있어요. "방금 만든 영상 열어 줘"라고 해도 돼요.

    ②AI에게도 검수를 시켜요

    고쳐서 다시 만들고, 규칙으로 남기기

    6분내 규칙

    목표: 고칠 점을 반영하고, "앞으로도 이렇게"로 내 규칙을 만들어요. 말투·금지어는 원하는 대로 바꿔도 돼요.

    핵심은 "앞으로도"예요. 마음에 안 들었던 순간이 규칙이 되고, 규칙이 쌓일수록 영상이 내 스타일이 돼요.

    바꾼 스킬로 한 편 더, 그리고 올릴 준비

    8분마무리

    목표: 내 스타일이 들어간 두 번째 영상을 만들고, 유튜브에 올릴 글까지 받아요.

    ①두 번째 영상 + 올릴 때 쓸 제목·설명·태그
    ②(집에서) 휴대폰 유튜브 앱으로 올리기
    1. 영상 파일을 카카오톡 "나와의 채팅"으로 보내 휴대폰에 저장해요.
    2. 유튜브 앱 → 아래 + → Shorts → 저장한 영상 선택
    3. ①에서 받은 제목·설명·태그를 붙여 넣고, 공개 범위는 처음엔 비공개로.
    4. 목소리를 AI로 만들었으니 "AI로 만든 콘텐츠"를 물으면 사실대로 체크해요.

    내 프롬프트 모음 가져가기

    5분파일 2개 저장

    오늘 쓴 프롬프트와, 유료로 바꾸면 바로 쓸 영상 만들기 프롬프트까지 내 채널 정보로 채워서 파일 하나로 드려요.

    ①오늘 모은 프롬프트

      ②나중에 혼자 할 때 쓰는 가이드
      쇼츠 혼자 시작하기 가이드 내려받기
      ③유료로 바꾼 날 이렇게 쓰세요
      1. AI 유료 구독(ChatGPT Plus·Claude Pro 등)과 데스크톱 앱 준비
      2. AI 앱 대화창에 가이드 파일을 끌어다 놓고 아래 문장을 붙여 넣기
      3. AI가 설치 → 폴더 열기를 안내하면, 내 프롬프트 모음의 "유료로 바꾸면" 프롬프트를 순서대로 넣기

      이 파일을 읽고, 내가 지금 해야 할 일을 한 단계씩 알려 줘. 한 번에 하나씩만.파일과 함께 보낼 말

      오늘 채팅에서 받은 대본(미션 2·3)과 내 채널 규칙(미션 4)은 메모장에 저장해 두세요. 프롬프트 모음의 "미리 만든 대본·규칙 넣기"와 함께 쓰면 바로 영상이 돼요.

      실습 끝!

      오늘 한 것: 채널 정하기 → 만들기 → 검수 → 규칙 → 화면 → 스킬 → 올릴 준비. 집에서도 이 순서를 반복하면 돼요.
