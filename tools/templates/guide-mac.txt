이슈킬러 쇼츠 제작 환경 — Mac 설치 안내 (영상 제작 전용)

■ 조건
  - macOS 13 (Ventura) 이상, Apple Silicon 또는 Intel
  - 여유 디스크 8GB 이상, 인터넷 (약 3GB 다운로드, 10~30분)
  - 관리자 비밀번호, Xcode, Homebrew 는 필요 없습니다

■ 설치 순서
  1. 이 폴더(issuekiller)를 홈 폴더(내 이름 폴더) 바로 아래에 둡니다.  (권장, 다른 위치도 됨)
  2. Spotlight(⌘+Space) 에서 "터미널" 을 검색해 엽니다.
  3. 터미널에  bash  를 입력하고 띄어쓰기 한 칸을 넣은 뒤,
     Finder 에서  setup/mac/install.command  파일을 터미널 창으로 끌어다 놓고 Enter 를 누릅니다.
  4. 끝날 때까지 기다립니다. (비밀번호는 묻지 않습니다)
  5. "설치가 모두 끝났습니다." 와 확인표의 ✅ 가 보이면 완료.
     ❌ 가 있으면 그 화면을 캡처해서 강사에게 보내주세요.
  6. 설치 끝. 강의 날: 쓰시는 AI 앱(ChatGPT·Claude·Gemini용 Antigravity)을 열고 홈 폴더의 issuekiller 폴더를 여세요.

■ 설치 후 쇼츠 만들기
  쓰시는 AI 앱 하나를 열고, 홈 폴더의 issuekiller 폴더를 열어 "쇼츠 만들어줘" 라고 말합니다.
    - ChatGPT 앱: Codex 를 열고 폴더 선택에서 issuekiller 를 고릅니다 (폴더를 신뢰한다고 답합니다)
    - Claude 앱: Code 탭에서 폴더로 issuekiller 를 고릅니다
    - Gemini: Antigravity 앱에서 issuekiller 폴더를 엽니다
  처음 한 번은 AI 가 유튜브 채널 이름을 묻습니다 (영상 왼쪽 위에 들어갑니다).
  만든 영상은 issuekiller/output 폴더에 저장되고, 요청하기 전에는 유튜브에 올리지 않습니다.

■ 나중에 상태만 다시 보려면
  같은 방법으로  setup/mac/check.command  를 실행합니다.

■ 설치되는 것 (모두 ~/issuekiller-tools 한 폴더와 이 프로젝트 폴더 안에만 들어갑니다)
  Node.js, ffmpeg, Python 3.12 + 음성 합성/검증 패키지, 음성 모델, Claude Code(터미널용, 선택),
  영상 프로젝트(Remotion) 패키지와 렌더용 브라우저, 확인용 2초 영상(test-render.mp4)

■ 다 지우려면
  ~/issuekiller-tools 폴더, 이 프로젝트 폴더, ~/.cache/supertonic3, ~/.cache/huggingface 를 지우고
  ~/.zprofile 에서 "# 이슈킬러 쇼츠 제작 도구" 아래 한 줄을 지웁니다.

■ 명령어 한 줄로 설치하기 (이 zip 없이도 됩니다)
  터미널에 아래 한 줄을 붙여넣고 Enter. 프로젝트 폴더를 ~/issuekiller 에 만들고 설치까지 이어서 합니다.
  curl -fsSL https://raw.githubusercontent.com/__GH_REPO__/main/get.sh | bash
  최신 안내: https://github.com/__GH_REPO__
