# YouTube 업로드

## 먼저 지킬 것

- **수강생이 "올려줘", "업로드해줘"처럼 명시적으로 요청하기 전에는 업로드하지 않는다.**
  요청이 없으면 최종 MP4 경로와 완성된 `youtube-upload.md` 를 알려주고 끝낸다.
- 공개 상태 기본값은 **비공개**다. 수강생이 "공개로"라고 명시한 경우에만 공개(또는 일부 공개)로 한다.
- 올리는 파일은 최종 MP4 **한 개뿐**이다. Markdown, JSON, 이미지, wav 파일은 절대 올리지 않는다.
- 연습용 이미지(`make_placeholders.py`)로 만든 영상은 올리지 않는다.
- 로그인은 수강생이 직접 한다. 비밀번호, 쿠키, 토큰을 묻거나 입력하거나 파일에 적지 않는다.
- 브라우저를 조작할 도구가 없으면, 아래 "Studio 입력 순서"를 수강생이 따라 할 수 있게 쉬운 말로 안내한다.

## 메타데이터

제목:

- 해시태그를 뺀 본문 20~35자를 목표로 한다.
- 첫 어절에 검증된 숫자나 결과를 둔다. 인물 이름은 그 다음이어도 된다.
- 제목 해시태그는 0~1개. 넣는다면 인물명 하나만 쓴다.
- 나머지 해시태그는 설명란으로 옮긴다.
- `~에 내놓은 답`, `~한 마음`처럼 힘이 약한 서술형 종결을 쓰지 않는다.
  `~한 이유`, `~라고 밝혔다`, `결국 ~했다`처럼 결과가 드러나는 형태를 쓴다.

설명:

```text
[핵심 요약 1~2문장]

출처:
[기사 URL]
[공식 원본 URL]

이 영상은 AI를 활용하여 만들어졌습니다. 내용은 모두 검수 후 업로드합니다.

#[인물] #[핵심주제] #[채널이름]
```

`#[채널이름]` 은 `channel.json` 의 `name` 에서 띄어쓰기를 뺀 것이다 (`scaffold_short.py` 가 `youtube-upload.md` 에 미리 채워 둔다).

상세 태그:

- 500자 이내
- 인물명, 다른 표기, 프로그램, 사건, 연관 검색어, 채널 주제
- 무관한 인기 검색어와 반복 태그 금지

## Studio 입력 순서

1. 로그인된 채널이 `channel.json` 의 채널(수강생 본인 채널)인지 확인한다.
2. 반드시 최종 MP4 한 개만 선택한다.
3. 제목과 설명을 입력한다.
3-1. 썸네일 `파일 업로드`로 `thumbnail.jpg`를 올린다. 첫 프레임과 같은 화면이어야 한다.
4. `아니요, 아동용이 아닙니다`를 선택한다.
5. 고급 설정에서 `예, AI가 사용되었습니다`(변경되거나 합성된 콘텐츠)를 선택한다.
6. 상세 태그를 입력한다.
7. 동영상 요소 단계를 지나 저작권 검사가 완료될 때까지 기다린다.
8. `발견된 문제가 없습니다`를 확인한다.
9. 공개 상태를 선택한다. 수강생이 명시하지 않았으면 **비공개**다.
10. 저장 후 Studio 목록에서 다시 확인한다.

## 최종 검증

- 제목이 올바른가
- 재생 길이가 렌더 결과와 같은가
- 공개/일부 공개/비공개가 요청과 같은가 (요청이 없었다면 비공개)
- 저작권 또는 처리 오류가 없는가
- YouTube URL이 실제 영상 ID와 일치하는가

## 실패 시

- 처리 중단: MP4 코덱과 파일 손상을 검사하고 다시 렌더한다.
- 저작권 문제: 공개하지 말고 문제 장면 또는 오디오를 교체한 뒤 재검사한다.
- 잘못된 파일 업로드: 수강생에게 알리고, 수강생 확인 후 삭제하고 MP4만 다시 올린다.
- 공개 상태 오류: 수강생에게 확인한 뒤 Studio에서 수정하고 목록에서 재확인한다.

## Studio 입력 시 주의 (브라우저 도구로 진행할 때, 2026-08-30 확인)

- 업로드 창은 `https://studio.youtube.com/` → 채널 → `.../videos/short?d=ud` 로 직접 이동하면 바로 열린다.
  `만들기` 메뉴 클릭은 자주 닫혀서 실패한다.
- 업로드 직후 다이얼로그가 다시 그려지면서 **제목·설명 입력이 통째로 유실되는 일이 잦다.**
  파일 업로드 후 5~7초 기다리고, 입력할 때마다 스크린샷으로 실제 반영을 확인한다.
- 요소 ref는 다이얼로그 재렌더 시 무효가 된다. 입력이 안 들어가면 좌표 클릭으로 다시 시도한다.
- 저장 후 목록에서 공개 상태를 재확인한다. 다만 **수강생이 직접 공개로 바꿔둔 것을 오설정으로 오인해
  되돌리지 않는다.** 상태가 요청과 다르면 먼저 수강생에게 확인한다.
