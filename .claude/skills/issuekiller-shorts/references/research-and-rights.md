# 조사·검증·권리 기준

## 조사 순서

1. 네이버 엔터테인먼트 랭킹
2. 방송사·소속사·당사자 공식 SNS/YouTube
3. 연합뉴스 등 신뢰할 수 있는 기사
4. 네이트 연예·판, 더쿠, 인스티즈 등은 화제성 탐색에만 사용

커뮤니티 글은 출처가 아니라 후보 탐색 수단이다. 핵심 사실은 기사나 공식 자료로 다시 확인한다.

## 최소 검증 기록

`source-info.md`에 다음을 남긴다.

- 랭킹에서 발견한 시점과 제목
- 핵심 주장별 확인 출처
- 공식 원본 URL
- 기사 게시 날짜와 사건 발생 날짜
- 불확실하거나 제외한 내용
- 시각 자료 파일과 원출처의 대응

## 위험한 표현

- 수사 중: `혐의를 받는다`, `경찰이 송치했다`
- 재판 전: `유죄가 확정된 것은 아니다`
- 건강: 의료진 또는 당사자가 공개한 범위만 전달
- 관계: `불화`, `이혼`, `열애`는 공식 확인 없이는 단정 금지
- 금액: 월세·연세·보증금·연봉을 혼동하지 말고 원문 단위를 확인

## 이미지·영상 사용

- 가능하면 당사자 공식 채널, 보도용 사진, 공식 SNS를 우선한다.
- 방송 영상은 논평과 정보 전달에 필요한 짧은 구간만 사용한다.
- 원본을 그대로 재업로드하지 않고 내레이션, 구조, 자막, 해설로 실질적 변형을 만든다.
- 설명란에 원본·기사 링크를 표시한다.
- 동일 사진을 크롭·반전하여 여러 장으로 부풀리지 않는다.
- 소재는 통신사·언론사·공영방송 자료를 우선한다. 연예인 개인 유튜브 캡처는 원저작자의 수동 삭제 요청 위험이 높다(실제로 개인 채널 캡처 위주 영상이 삭제 요청과 경고를 받은 사례가 있다).
- 개인 유튜브 캡처는 최소화한다. 워터마크·로고가 노출된 프레임은 쓰지 않고 다른 자료로 교체한다. 워터마크를 지우거나 숨기려고 크롭·반전하지 않는다.
- 기사 사진이라도 유튜브 채널 워터마크가 찍혀 있으면 개인 유튜브 캡처로 간주한다.
- 단일 출처 캡처만으로 영상 전체를 구성하지 않는다.
- YouTube 검사에서 문제가 있으면 공개하지 말고 해당 자산을 교체한다.
