# 쇼츠 제작 (이슈킬러 강의 실습)

사용자는 40~50대 비개발자 수강생이다. 명령어는 AI(에이전트)가 직접 실행하고, 수강생에게는 쉬운 말로 지금 무엇을 하는지
한두 줄씩만 알려준다. 수강생에게 터미널 명령을 입력하라고 하지 않는다.

## 시작 전에 읽을 파일

- **내 규칙**: 프로젝트 폴더의 `my-rules.md`. 이 스킬의 기본값보다 우선한다(절대 규칙보다는 아래). 매번 먼저 읽는다.
- **내 스킬**: 프로젝트에 `.agents/skills/my-shorts/` 가 있으면 이 스킬 대신 그것을 따른다(지금 읽는 것이 `my-shorts` 면 그대로 진행). 자세한 규칙은 `AGENTS.md` 의 "내 것으로 바꾸기".
- 채널과 편집 판단: `references/channel-playbook.md`
- 실제 경로와 명령: `references/production-pipeline.md`
- 조사·검증·저작권: `references/research-and-rights.md`
- YouTube 업로드 정보와 검증: `references/youtube-upload.md` (업로드는 수강생이 명시적으로 요청할 때만)

## 처음 한 번: 채널 이름

채널 이름은 프로젝트 폴더의 `channel.json` 한 곳에만 있다. 화면 왼쪽 위 배지, 업로드 문서의 해시태그가 여기서 나온다.

```json
{
  "name": "내 채널",
  "tagline": "구독 · 좋아요로 다음 이슈 받기"
}
```

- 작업을 시작할 때 `channel.json` 을 읽는다. `name` 이 아직 `내 채널` 이면 영상 작업 전에 수강생에게
  "유튜브 채널 이름이 무엇인가요? 영상 왼쪽 위에 들어갑니다." 라고 묻고, 답을 받아 `name` 만 바꿔 저장한다.
  (`tagline` 은 수강생이 바꾸고 싶다고 할 때만 바꾼다. JSON 형식을 깨지 않게 큰따옴표를 지킨다.)
- 수강생이 "그냥 두세요"라고 하면 `내 채널` 그대로 진행한다.
- 채널 이름을 화면 템플릿(`src/NewsTemplate.tsx`)이나 다른 파일에 직접 쓰지 않는다.

## 화면 모양 바꾸기 (색 · 글씨 크기 · 배지 · 자막 상자)

"배지 색 바꿔 줘", "제목 글씨 더 크게", "자막 상자를 흰 바탕에 검은 글씨로" 같은 요청은 **`theme.json` 한 파일**로 처리한다.
`src/NewsTemplate.tsx` 는 고치지 않는다 (템플릿이 `theme.json` 을 읽는다). 오른쪽 위 문구의 글자는 `channel.json` 의 `tagline`.

1. `theme.json` 에서 요청에 해당하는 키만 고친다. 큰따옴표·쉼표를 지키고 주석을 넣지 않는다. 색은 `"#RRGGBB"` 또는 `"rgba(r,g,b,a)"`.
2. 미리보기 한 장을 뽑아 직접 열어 확인한 뒤 수강생에게 보여 준다 (가장 최근 영상의 2초 화면, 덮어쓰지 않고 번호가 붙는다):
   `bash scripts/py.sh .agents/skills/issuekiller-shorts/scripts/preview_still.py`
   → `qc/<asset-root>/theme-preview-NN.jpg`. 훅 카드는 `--seconds 0.4`, 다른 영상은 `--composition-id <ID>`.
3. 제목·자막이 안전 영역 밖으로 밀리거나 사진의 얼굴을 너무 가리면 크기 조절값을 줄여 다시 확인한다.
   글씨와 바탕 색이 비슷해 읽기 어려우면 대비가 큰 색을 제안한다.
4. 영상 파일에도 반영하려면 새 이름으로 다시 렌더한다 (`render_short.py ... --output output/<asset-root>-v2.mp4`).
   새로 만드는 영상에는 자동으로 적용된다.

| 키 | 바뀌는 곳 | 기본값 |
|---|---|---|
| `backgroundColor` | 화면 바탕·사진 위아래 어두운 그림자 | `"#0d0f13"` |
| `titleColor` / `titleSizeAdjust` | 위쪽 제목 글씨 색 / 크기 조절(영상 크기에 더함, -40~60) | `"#ffffff"` / `0` |
| `badgeColor` / `badgeTextColor` | 왼쪽 위 채널 배지 바탕 / 글씨 | `"#ffcc4d"` / `"#111318"` |
| `taglineColor` / `taglineSize` | 오른쪽 위 문구 색 / 크기(14~60) | `"rgba(255,255,255,0.94)"` / `25` |
| `sceneLabelColor` / `sceneLabelTextColor` | 장면 이름표 바탕+왼쪽 세로 줄(`""` = 장면마다 다른 색) / 글씨 | `""` / `"#111318"` |
| `captionBoxColor` / `captionTextColor` | 자막 상자 바탕 / 글씨 | `"rgba(7,9,12,0.94)"` / `"#fffdf6"` |
| `captionSizeAdjust` | 자막 글씨 크기 조절(영상 크기에 더함, -40~60) | `0` |
| `highlightColor` / `highlightTextColor` | 강조 단어 형광펜 바탕 / 글씨 | `"#ffdf63"` / `"#111318"` |
| `fontFamily` | 글꼴 이름(설치된 글꼴만, `""` = 기본) | `""` |

| 요청 | 고칠 키 |
|---|---|
| 배지를 초록색으로 | `badgeColor` `"#2E7D32"` + `badgeTextColor` `"#ffffff"` |
| 제목 글씨 더 크게 | `titleSizeAdjust` `8` (더 크게면 `16`) |
| 자막 상자 흰 바탕에 검은 글씨 | `captionBoxColor` `"#ffffff"` + `captionTextColor` `"#111111"` |
| 오른쪽 위 문구를 "매주 금요일 새 영상"으로 | `channel.json` 의 `tagline` |
| 강조 단어를 분홍색으로 | `highlightColor` `"#ff8fb1"` |

원래 모양으로 되돌리려면 그 키를 지우거나 표의 기본값으로 되돌린다. `theme.json` 파일 자체는 지우지 않는다
(지워졌으면 렌더·미리보기 스크립트가 기본값으로 다시 만든다). 값이 틀리면 그 키만 기본값으로 그려지고, JSON 형식이 깨지면
스크립트가 몇째 줄이 틀렸는지 알려 주고 멈춘다.

## 명령 실행 규칙

- 모든 명령은 프로젝트 폴더(Mac `~/issuekiller`, Windows `%USERPROFILE%\issuekiller`)에서 실행한다.
- 도구(python·ffmpeg·ffprobe·npx)를 이름만으로 부르지 않는다. 앱에서는 PATH 에 도구가 없을 수 있다.
  항상 아래 **실행기**로 부른다. 실행기가 `~/issuekiller-tools` 의 가상환경 Python 과 도구 경로를 알아서 붙인다.

  | 셸 | 실행기 (명령 맨 앞) |
  |---|---|
  | Mac (zsh/bash), Windows Git Bash | `bash scripts/py.sh` |
  | Windows PowerShell, cmd | `scripts\py.cmd` |

  - Python 스크립트: `bash scripts/py.sh <스크립트.py> [인자]`
  - ffmpeg·ffprobe·npx: `bash scripts/py.sh scripts/tool.py ffmpeg [인자]` (`ffprobe`, `npx` 도 같은 형식)
  - 이 문서와 `references/` 의 예시는 모두 한 줄짜리 `bash scripts/py.sh ...` 형식이다. Windows PowerShell 이면
    맨 앞 `bash scripts/py.sh` 만 `scripts\py.cmd` 로 바꾸고 나머지는 그대로 쓴다. 인자는 큰따옴표로 감싼다.
  - 시스템의 `python3`/`python` 은 쓰지 않는다 (numpy·pillow·supertonic 이 없다).
- 이미 있는 영상·자산 폴더를 덮어쓰지 않는다. 같은 소재를 다시 만들면 새 `--asset-root`/`--composition-id` 를 쓴다.
- `src/NewsTemplate.tsx`, `src/Root.tsx` 는 고치지 않는다. 새 영상은 `scaffold_short.py` 가 만드는
  `src/<ID>Composition.tsx` 와 `public/<asset-root>/` 에서만 다룬다. 화면 색·글씨 크기는 `theme.json` 에서 바꾼다.

## 작업 목표

40~60대 여성 시청자가 첫 2초 안에 상황을 이해하고 끝까지 본 뒤 자신의 경험이나 생각을 댓글로 남길 수 있는 30~48초의 사실 기반 Shorts를 만든다.

## 필수 순서

1. 현재 날짜를 확인하고, `output/` 폴더의 이전 작업과 수강생이 알려준 최근 업로드를 확인한다.
2. 네이버 엔터 랭킹을 먼저 보고 네이트, 공개 커뮤니티, 방송·공식 YouTube 흐름을 보조로 확인한다.
3. 최근 업로드와 인물, 사건, 핵심 관점이 겹치는 후보를 제외한다.
4. 최소 2개의 신뢰할 수 있는 출처로 핵심 사실을 교차 검증한다.
5. 소재를 고르기 전에 장면 수만큼 실제로 다른 시각 자료를 확보할 수 있는지 확인한다.
6. 첫 문장에 가장 강한 확인 사실을 넣고 8~10개 장면의 대본을 쓴다.
6-1. 첫 1.1초를 채울 훅 카드 문구와 얼굴 클로즈업 이미지(`hook.jpg`)를 만든다.
7. 자산 폴더와 Composition은 `scripts/scaffold_short.py`로 만든다.
8. Supertonic으로 음성을 만들고 `scripts/sync_timing.py`로 장면을 음성에 맞춘다.
9. `scripts/render_short.py`로 렌더와 자동 검수를 수행한다.
10. 콘택트시트를 직접 보고 제목·자막·얼굴·이미지 중복을 확인한다.
11. 업로드 정보 문서(`youtube-upload.md`)를 완성하고, 최종 MP4 경로와 함께 수강생에게 알려준다.
12. 업로드는 수강생이 "올려줘"처럼 **명시적으로 요청한 경우에만** `references/youtube-upload.md` 대로 진행한다.
    공개 상태는 수강생이 공개를 명시하지 않으면 비공개다. 업로드 후 Studio 목록에서 제목, 30~48초 길이, 공개 상태, URL을 재확인한다.

### 연습 모드

수강생이 "연습", "테스트", "아무 주제나"라고 하거나 실제 사진을 쓰기 어려운 경우, 실존 인물이 없는 가벼운 주제로
대본을 쓰고 `scripts/make_placeholders.py` 로 연습용 이미지를 만들어 전체 과정을 끝까지 돌린다.
연습용 이미지로 만든 영상은 업로드하지 않는다. 장면 수는 3~4개로 줄여도 되지만 음성 전체가 20초 이상이 되게
장면마다 두 문장 정도로 쓴다 (20초 미만은 자동 검수 `[FAIL]`, 20~30초의 길이 `[WARN]` 은 연습이면 무시해도 됨).

## 대본 규칙

- 첫 2초: 인물 이름과 가장 강한 사실을 즉시 제시한다.
- 한 문장에는 한 가지 확인 사실만 넣는다.
- 날짜, 나이, 금액, 관계, 진단, 법적 상태는 원문을 다시 확인한다.
- 기사에 없는 감정, 의도, 인과관계를 만들지 않는다.
- 건강·수사·법률은 단정하지 않는다.
- 문장 사이 침묵이 생기지 않게 쓴다.
- 마지막은 소재와 직접 연결된 질문 뒤에 `공감하셨다면 댓글로 남겨주세요.`를 붙인다.

## 시각 규칙

- 1080x1920, 30fps.
- `layoutPreset: "shorts-safe-v2"`와 `showProgress: false`를 사용한다.
- 상단 채널 배지와 제목은 안전 영역 안에 둔다.
- 본문 자막은 중앙 아래쪽에 두고 오른쪽 UI 영역을 비운다.
- 자막마다 실제로 다른 원본 사진 또는 다른 시간대의 영상 프레임을 사용한다.
- 동일 사진의 확대, 크롭, 좌우 반전은 중복이다.
- 얼굴과 핵심 행동을 자막이 과하게 가리면 이미지 위치나 자막 길이를 바꾼다.
- 원본 자막·기사 UI가 본문 자막 뒤에 겹치지 않게 합리적으로 크롭한다.
- **수강생 기본(실습·일반 주제)**: 사진은 저작권 걱정 없는 무료 사진 사이트에서 찾는다.
  Pexels, Unsplash, Pixabay 를 우선하고, Wikimedia Commons 는 라이선스(CC0·CC BY 등)를 확인해 출처 표기 조건을 지킨다.
  뉴스·블로그·쇼핑몰·SNS 사진은 쓰지 않는다. 장면마다 다른 사진을 쓰고, 사진마다 원본 페이지 주소와 라이선스를
  `public/<asset-root>/source-info.md` 에 적는다. 주제에 맞는 사진을 찾지 못한 장면만 `scripts/make_placeholders.py` 로 채운다.
- 수강생이 직접 찍은 사진을 주면 그것을 가장 먼저 쓴다.
- (강사 채널처럼 연예 이슈를 다루는 경우에만) 뉴스 통신사·언론사·공영방송 자료를 쓰되, 연예인 개인 유튜브 캡처는 최소화한다.
- 개인 유튜브 캡처를 불가피하게 쓸 때는 채널 워터마크·로고가 프레임에 남은 것을 그대로 쓰지 않는다. 워터마크가 보이는 프레임은 다른 자료로 교체한다.
- 한 출처(특히 개인 채널 하나)의 캡처만으로 영상 전체를 구성하지 않는다. (실제 사례: 개인 채널 캡처만으로 만든 영상이 원저작자의 삭제 요청과 경고를 받았다.)

## 첫 1초 규칙

Shorts는 첫 1초에 넘길지 말지가 갈린다. (강사 채널 기준 유효 조회 52%, 이탈 43.2%)

- 모든 영상은 `hook` 설정을 넣는다. 기본 지속 시간 1100ms.
- 훅 카드에서는 상단 제목, 본문 자막, 장면 라벨을 전부 감춘다. 화면에 글자는 채널 배지와 훅 문구만 남긴다.
- 훅 문구는 **두 줄, 각 줄 8자 이내**. 가장 강한 숫자나 결과를 앞줄에 둔다.
- 뒷줄(또는 핵심 어절)은 `highlight`로 노란 배경 처리한다.
- 훅 이미지는 `hook.jpg`로 따로 만든다. 원본을 9:16으로 크롭해 **인물 얼굴이 화면을 채우게** 한다.
  와이드샷, 패널샷, 자막이 박힌 프레임은 훅에 쓰지 않는다.
- 훅에는 진입 애니메이션을 넣지 않는다. 0프레임부터 완전히 보여야 한다.
- 훅 문구와 첫 장면 나레이션은 같은 사실을 가리켜야 한다. 훅에서 약속한 것을 바로 이어받는다.
- 렌더 후 0.4초 프레임을 뽑아 커스텀 썸네일(`thumbnail.jpg`)로 쓴다. 첫 프레임이 곧 썸네일이다.

## 음성 규칙

- 기본 음성: Supertonic `F1`.
- 기본 속도: `1.22`; 감정이 부자연스러우면 `1.18~1.20`으로 낮춘다.
- TTS 생성 후 문장 앞뒤 침묵을 제거하고 `-16 LUFS` 수준으로 정규화한다 (생성 스크립트가 자동 처리).
- 0.25초 이상의 불필요한 무음은 실패로 처리한다.
- 음성 구간과 자막 시작·종료를 정확히 맞춘다.

## 업로드 규칙

- 업로드는 수강생의 명시적 요청이 있을 때만 한다. 요청이 없으면 MP4 와 `youtube-upload.md` 까지만 만든다.
- 제목 첫 어절에 검증된 숫자나 결과를 놓는다. 인용구나 부드러운 서술로 시작하지 않는다.
- 제목 해시태그는 0~1개만 쓴다. 해시태그가 제목 앞부분을 잡아먹으면 안 된다.
- 해시태그를 뺀 제목 본문은 20~35자를 목표로 한다.
- 기사에서 캐낸 추가 숫자(기간·나이·금액·횟수)를 하나 더 넣어 클릭 이유를 만든다.
- 확인되지 않은 숫자는 넣지 않는다. 출처 2곳에 없으면 뺀다.
- 설명은 핵심 요약, 출처 링크, 아래 문구, 관련 해시태그(마지막에 채널 해시태그) 순서로 쓴다.
- 필수 문구: `이 영상은 AI를 활용하여 만들어졌습니다. 내용은 모두 검수 후 업로드합니다.`
- 상세 태그는 500자 이내에서 인물, 프로그램, 사건, 연관 검색어, 채널 주제를 사용한다.
- `아동용 아님`과 `AI 사용`을 정확히 표시한다.
- MP4 외 파일은 업로드하지 않는다. Markdown, JSON, 이미지 파일은 올리지 않는다.
- 수강생이 공개를 명시하지 않으면 비공개다.
- 저작권 검사에 문제가 있으면 게시하지 말고 자산을 교체한다.
- 계정 비밀번호, 쿠키, 토큰을 코드나 문서에 기록하지 않는다. 로그인은 수강생이 직접 한다.

## 완료 조건

- 출처 2개 이상과 검증 메모가 있다 (`source-info.md`).
- 장면 수와 음성·자막 수가 같다.
- 이미지의 정확 중복이 없고 유사도 경고를 직접 확인했다.
- 1080x1920 H.264 영상과 오디오 스트림이 있다.
- 0.25초 이상 무음과 긴 검은 화면이 없다.
- 여러 시점의 프레임에서 제목과 자막이 잘리지 않고, 왼쪽 위 배지에 채널 이름이 보인다.
- `youtube-upload.md` 의 제목, 설명, 상세 태그, AI 표시, 공개 상태(기본 비공개)가 채워져 있다.
- 최종 응답에 로컬 MP4 경로(업로드했다면 YouTube URL도)를 남긴다.
